The Method, Four Steps

  1. Find the interesting octet — the one where the mask is not 255 or 0.
  2. Block size = 256 − the mask value in that octet.
  3. Network = the largest multiple of the block size that is ≤ the address in that octet. Octets to the right become 0.
  4. Broadcast = next network − 1 (octets to the right become 255). Usable = network + 1 through broadcast − 1.
Check Yourself

Hosts = 2host bits − 2. Subnets from borrowing n bits = 2n. Private ranges: 10/8, 172.16/12, 192.168/16. Never assign the network or broadcast address.
