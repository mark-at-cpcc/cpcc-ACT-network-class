Subnetting: CIDR, Masks, and Block Sizes

Technical Overview

A subnet mask divides an address into network bits and host bits. CIDR notation writes the mask as the count of network bits: /26 means 26 ones, which is 255.255.255.192. Borrowing host bits creates subnets: each borrowed bit doubles the number of subnets and halves their size. For a prefix p there are 2(32−p) addresses per subnet and 2(32−p) − 2 usable hosts (the network and broadcast addresses are reserved; a /31 point-to-point link and a /32 host route are the exceptions). The block size — 256 minus the mask value in the interesting octet — gives the subnet boundaries directly. VLSM (variable-length subnet masking) gives each subnet only the size it needs, largest first.

In Plain Terms — the Magic Number

Find the octet where the mask is not 255 or 0. Subtract that mask value from 256: that is the block size, the “magic number.” Subnets start at every multiple of it. For 192.168.10.77/26: the mask is 255.255.255.192, 256 − 192 = 64, so subnets start at .0, .64, .128, .192. Seventy-seven falls in the .64 block: network .64, broadcast .127, usable .65–.126, 62 hosts. Four steps, no binary required once you trust it.

Worked VLSM, once

Allocate 192.168.50.0/24 to a sales LAN of 100 hosts, an office LAN of 50, a server LAN of 20, and two router links. Largest first: sales needs 102 addresses → /25 = .0–.127; office needs 52 → /26 = .128–.191; servers need 22 → /27 = .192–.223; each link needs 2 → /30 = .224–.227 and .228–.231. Nothing overlaps, and .232–.255 is left for growth.

Where Students Trip

Off-by-one at the boundaries. The network address is the first in the block and the broadcast is the last; neither is a host. A host address of .64 in a /26 is the network address and cannot be assigned. The exam builds distractors from exactly these mistakes.

Troubleshooting IP Addressing

Technical Overview

Chapter 8’s method: from the host out, ping the loopback (127.0.0.1, the stack), the host’s own address (the NIC), the default gateway (the local network), and a remote host (routing). The four classic faults are a wrong mask (the host misjudges what is local), a wrong gateway (local works, remote does not), a duplicate address (intermittent, with an ARP conflict warning), and an address on the wrong subnet for its VLAN.

NAT and PAT

Technical Overview

Network Address Translation rewrites addresses at the boundary. Static NAT maps one private address to one public address (a published server). Dynamic NAT maps private hosts to a pool. PAT (NAT overload) maps many private hosts to one public address by tracking source ports — what every home router does. Terms: inside local (private address as seen inside), inside global (its public address).

Routing

Technical Overview

A router forwards each packet by the longest matching prefix in its routing table, then by administrative distance (trust in the source: connected 0, static 1, eBGP 20, EIGRP 90, OSPF 110, RIP 120, iBGP 200), then by the protocol’s metric. A default route (0.0.0.0/0) catches everything not more specific. Static routes are typed by hand; dynamic protocols learn: RIP is distance-vector with a hop-count metric (max 15); OSPF is link-state with a cost metric and areas; EIGRP is an advanced distance-vector (hybrid) protocol; BGP is the path-vector protocol between autonomous systems on the internet. FHRP (VRRP, HSRP) lets two routers share a virtual gateway IP. A subinterface lets one physical router port carry several VLANs (router-on-a-stick).

Longest match first, then trust, then cost

A packet for 10.1.5.9 with routes to 10.0.0.0/8 (OSPF) and 10.1.5.0/24 (static) takes the /24 — more specific always wins before administrative distance is even considered. AD only breaks ties between routes to the same prefix. Most routing exam questions are this sentence in disguise.

Switching and VLANs

Technical Overview

A switch learns source MAC addresses per port and forwards by destination MAC, flooding unknowns. A VLAN divides one switch into separate broadcast domains; an access port carries one VLAN; a trunk carries many, tagging frames with 802.1Q — except the native VLAN, which crosses untagged and must match on both ends. A voice VLAN lets a phone and the PC behind it share a port. Traffic between VLANs needs a router, a router-on-a-stick, or a Layer 3 switch with SVIs. Spanning Tree (802.1D; RSTP 802.1w) elects a root bridge and blocks redundant paths so frames cannot loop; ports move through blocking, listening, learning, forwarding. Interface settings: speed and duplex (mismatch causes collisions and errors), link aggregation (LACP bundles ports), PoE (802.3af 15.4 W, 802.3at 30 W, 802.3bt 60–100 W), MTU and jumbo frames (9000 bytes, which must match end to end), and port mirroring for capture.

Where Students Trip

A native-VLAN mismatch does not break the trunk; it quietly leaks untagged traffic into the wrong VLAN and logs warnings. A trunk that is not allowing a VLAN looks fine and passes everything except that VLAN. Unit 6 tickets live on these two faults.

Beyond the Exam

VTP and its modes (Chapter 11, pp. 409–411) are Cisco-specific and not named in the N10-009 objectives. Read for context.
