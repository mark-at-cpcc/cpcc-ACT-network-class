1.B — Clearing Your Browser Cache
Return to Index

If a course page looks out of date, shows an old score, or a quiz will not load, your browser is probably showing you a saved copy. Clearing the cache fixes it in under a minute.

Why This Happens

Browsers keep copies of pages to load them faster. When a course page is updated, your browser may keep showing the copy it saved earlier. Every course page asks the browser not to do this, but some browsers do it anyway.

The Quick Fix: a Hard Refresh

  1. Windows: hold Ctrl and press F5 (or Ctrl + Shift + R).
  2. Mac: hold Cmd + Shift and press R.
  3. If the page still looks wrong, clear the cache for the browser using the steps below.

Clearing the Cache

Google Chrome and Microsoft Edge

  1. Press Ctrl + Shift + Delete (Mac: Cmd + Shift + Delete).
  2. Set the time range to All time.
  3. Check Cached images and files only. Leave passwords and history unchecked.
  4. Click Clear data, then reload the course page.

Firefox

  1. Press Ctrl + Shift + Delete.
  2. Set When to Everything, check Cache only, and click Clear Now.

Safari

  1. Open Safari → Settings → Advanced and turn on Show features for web developers.
  2. From the Develop menu choose Empty Caches, then reload.
Still Not Right?

Open the page in a private or incognito window. If it looks correct there, the cache was the problem and the steps above will fix it in your normal window. If it still looks wrong, send me a screenshot.
